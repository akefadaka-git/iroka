## Explicit G09 boundary

Persistent workspace writes are NOT IMPLEMENTED. The kernel's authenticated authorization API explicitly says an ALLOW decision is not an execution grant and requires G09 to exchange decision evidence for a short-lived grant. No G09 execution-grant API was found in the inspected kernel surface. C1.4 therefore does not add a filesystem writer or reinterpret G02 approval as permission to write files.

C1.5/G09 integration must provide the execution-grant boundary before persistent editing or isolated tool execution can be enabled. This is a deliberate fail-closed boundary, not an unverified completion claim.
