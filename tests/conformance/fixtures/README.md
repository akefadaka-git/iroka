# Conformance fixture baseline

This directory contains synthetic, non-sensitive starter fixtures for the IROKA A2 conformance program.

- `catalog.json` is the machine-readable test inventory.
- Fixture values in this document are smoke-test seeds, not a reviewed language-quality corpus.
- The Ethiopian calendar oracle, VYRAQON authoritative grammar/release fixtures and final INL grammar fixtures remain BLOCKED pending their governing decisions.
- Amharic fixtures require competent human review before they can serve as normative quality oracles.
- Never mark a case PASS until a runnable harness executes it against an exact SHA and retains evidence.

The synthetic non-Ethiopian profile is a configuration-isolation fixture only; it is not a statement about local law or compliance.
